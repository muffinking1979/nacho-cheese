# Nacho Cheese

An octopus sits on a pile of 8 cheese wedges, facing 8 doors. Mice keep opening the doors to steal the cheese. Slam the doors shut before they get away!

**▶ Play it here: https://muffinking1979.github.io/nacho-cheese/**

## How to play

Each home-row key sends one of the octopus's arms to its door:

```
A  S  D  F        J  K  L  ;
```

- When a door opens and a mouse peeks out, press that door's key before the timer ring runs out to slam it. Each mouse caught is worth **100 points**.
- If you're too slow, the mouse runs out and takes a wedge of cheese.
- Catch **8 mice** to clear the round. Lose all 8 wedges and the mice win.
- Only one arm can reach at a time, and slamming an empty door tangles the octopus for a moment, so mashing keys won't save you.

### Round 2

- The mice are faster.
- Some doors hide **cheese** instead of a mouse. **Leave those doors open** and the wedge is added back to your pile (or worth +50 points if the pile is full). Slam one and the cheese is lost.

Your score and cheese carry over from Round 1 to Round 2.

## Running locally

It's one HTML file with no dependencies. Open `index.html` in any modern browser.
